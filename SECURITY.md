# Security policy

## Supported versions

Security fixes are provided for the latest `1.x` release.

## Reporting a vulnerability

Use GitHub private vulnerability reporting after the public repository is
available. Until then, contact the repository owner through the organization's
established private security channel. Do not include vulnerability details,
credentials, collector keys, or production data in a public issue.

Include the affected version, a minimal reproduction, impact, and suggested
mitigation when known. The maintainers will acknowledge the report privately
and coordinate disclosure after a fix is available.
